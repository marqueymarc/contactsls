A small macOS utility

contactsls

A read-only command-line viewer for your local macOS Contacts—sorted by when they were created, edited, or named.

brew install marqueymarc/tap/contactsls
View on GitHub

Useful from the first command

# The ten newest contacts
contactsls

# Find someone, including notes and contact details
contactsls --match "Dale Barnes" --details

# Associate a local Google Timeline export with creation times
contactsls --timeline ~/Downloads/location-history.json \
  --fields name,created,location
Local by defaultReads Contacts and Timeline files from your Mac; it never changes them.
Privacy-awareApple reverse geocoding is explicit: use --location only when you want it.
